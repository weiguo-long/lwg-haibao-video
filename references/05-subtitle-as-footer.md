# v3 核心：字幕即页脚、逐页取色、占位恒定

这一篇是 v2 → v3 的全部实质改动。三者是同一件事：**字幕是页面设计的一部分，不是外挂的播放控件。**

## 1. 三种做法的区别

| 做法 | 结构 | 观感 | 问题 |
|---|---|---|---|
| v2 独立字幕条 | 画面外底部 11.5% 深色通栏，海报整体缩到 0.885 放进上方安全区 | 像视频播放器 | 画面被压缩、构图出血被裁、字幕与页面是两套视觉系统 |
| 页脚让位（错误版） | 页面做完，把原页脚上移 4.6cqw，在底部新加一条字幕容器 | 仍是「后塞进去」 | 破坏原有留白节奏，字幕仍旧自带底色块 |
| **v3 字幕即页脚** | 把每页原本放页脚 / 页码的那个元素**整个替换**成字幕宿主 | 字幕长在版式里 | 需要逐页写替换规则；字幕色要按页取 |

判断标准：如果关掉配音、只截一帧，字幕看起来是否本来就该在那个位置。v3 的 8 页字幕位各不相同（bottom 3.2%–7%），跟着各自的版式走：03 在深蓝色块里、06 居中接在大量留白之后、04 是底部一条居中收尾。

## 2. 逐页替换规则（RULES）

在 `footer_rules.py` 里为每页写三件事：

```python
RULES[n] = dict(
    find = r'<div class="foot">.*?</div>',        # 原页脚 / 页码元素的正则
    html = '<div class="foot subhost"><p class="subline">{sub}</p></div>',
    css  = '#c{n} .foot.subhost{...} #c{n} .foot.subhost .subline{...}',
)
```

- `find` 必须**唯一命中一次**（`re.subn` 后 `assert cnt == 1`），否则会替换错元素或漏页。
- `html` 保留原元素的 class（`.foot` / `.pg` / `.src` / `.conclusion` / `.bottom-en`），只加 `subhost` 与内部 `subline`。保留 class 才能继承它原有的定位、栏线、色块与栅格。
- `css` 里**只写这个位置本来就该有的样式**：对齐、`gap`、padding、颜色、字号，不要重新定义一套字幕条。
- 页码、连载标签、英文装饰行、出处行全部取消；`VOL. 01 / 08` 只留期号。播放器控制条里的 `01 / 08` 是章节指示，不是画面元素，保留。

已验证的 8 页让位表（示例项目，换项目要重写）：

| 页 | 让出来的位置 | 字幕宿主 | 对齐 / 装饰 |
|---|---|---|---|
| 01 | 栏线下的信息行 + 页码 | `.foot.subhost` | 左，栏线继承 |
| 02 | 连载 02 + OLD NEEDS 英文行 | `.foot.subhost` | 左，朱红引导短线 |
| 03 | 底部深蓝结语句色块 | `.conclusion.subhost` | 块内，深蓝底 |
| 04 | MODEL T 描边大字行 | `.bottom-en.subhost` | 居中，去描边 |
| 05 | 右下角页码 | `.pg.subhost` | 左，朱红引导短线 |
| 06 | 居中页码 | `.pg.subhost` | 居中，大量留白后 |
| 07 | 右下角页码 | `.pg.subhost` | 左，朱红引导短线 |
| 08 | 《道德经》出处行 + 页码 | `.src.subhost` | 居中，`margin-top` 继承 |

**统一只管三件事**：`font-size:2.8cqw` / `font-weight:600` / `white-space:nowrap` 单行不折行；`letter-spacing:.02em`；`line-height:1.4`。字号层级、对齐与位置交给各页自己。

静态效果图阶段就用每页**最长的一条字幕**（14–24 字）展示最挤状态，先给用户确认版式，再动动画。效果图 HTML 用 `#P1`…`#P8` 锚点看 900×1200 单页全尺寸。

## 3. 逐页取色：字幕不能非黑即白

v3 初版把 8 页字幕统一刷成墨色 / 米白，等于在页面里另起了一套颜色。查原页 CSS 会发现每页都有明确的色彩层级，字幕应该**接该位置本来的文字色**：

| 页 | 底色 | 字幕色 | 取色依据 | 对比度 |
|---|---|---|---|---|
| 01 | 夜蓝深底 | `#C2BFBD` | 米白 `#F1E6D8` 掺灰蓝 `#4A5B78` 28%，呼应竖排 PRICE 水印 | 7.00:1 |
| 02 | 米白 | `#4A5B78` 灰蓝 | 原 `.foot-en` 页脚英文行 | 5.57:1 |
| 03 | 深蓝块 | `#C2BFBD` | 块内原米白的柔和化 | 7.00:1 |
| 04 | 米白 | `#28314E` 夜蓝 | 该页主文字（标题 / 数字 / 结语句） | 10.40:1 |
| 05 | 夜蓝深底 | `#C2BFBD` | 同 01 | 7.00:1 |
| 06 | 米白 | `#4A5B78` 灰蓝 | 诗文 `.poem` / `.poem-en` | 5.57:1 |
| 07 | 米白 | `#28314E` 夜蓝 | 底部 `.foot-box` 与 `.kana` | 10.40:1 |
| 08 | 米白 | `#28314E` 夜蓝 | `.punch` 结语句，与上方灰蓝引文分层 | 10.40:1 |

规则：

- 浅底页接该页**原有的次级或主文字色**（灰蓝或夜蓝），不用纯墨。
- 深底页用**米白与该页灰蓝调和出的浅色**，不要用纯白；在夜蓝底上明显比标题的纯米白柔一档，正好与页面半透明注释小字同级。
- 朱红 `#AA2B3A` 只作 ≤5% 的引导短线（`.submark`），不用于整行字幕。
- 对比度按 WCAG `(L1+0.05)/(L2+0.05)` 实算，全部 ≥ 5.5:1 才定稿。

实现上：在 `build_preview_v3.py` 里用 `SUB_COLORS` / `BASE_COLORS` 两张映射表，对 `RULES[n]["css"]` 里的颜色声明做正则替换。**只覆盖颜色，版式结构一个字不动**，静态效果图脚本与产物保持原状不回写。

## 4. 占位恒定：字幕消失时绝不清空文字

这是最容易漏、也最伤观感的一条。

**根因**：句间和每个场景末尾有约 0.803 秒没有字幕。若 `applySubtitle()` 在这段空档执行 `line.textContent = ''`，`.subline` 的行盒会塌成 0，页脚高度随之收缩，`flex` / 文档流里的上方元素被整组下拉。实测 8/8 页都抖：

| 现象 | 实测 |
|---|---|
| 页脚高度收缩 | 10.10–35.28 px（900×1200 画布） |
| 08 页 `.finale` / `.quote` / `.punch` 整组下移 | 35.28 px |
| 02 / 05 / 07 朱红短线下移 | ~5 px |
| 字幕盒宽度塌陷 | 最多 565.5 px |

**正确写法**（`build_preview_v3.py`）：

```js
const SUB_PLACEHOLDER = TIMELINE.scenes.map(s =>
  (s.subtitles && s.subtitles.length) ? s.subtitles[0].text : '\u3000');

function applySubtitle(t, idx, sub){
  const line = $('s'+(idx+1)).querySelector('.subline');
  if(!line) return;
  if(sub){
    if(line.textContent !== sub.text) line.textContent = sub.text;   // 换句才换文字
    const p = Math.max(0, Math.min(1, (t - sub.s) / SUB_FADE));      // 0.18s 淡入
    line.style.opacity = p < 1 ? (0.30 + 0.70*p).toFixed(3) : '1';
  }else{
    if(!line.textContent) line.textContent = SUB_PLACEHOLDER[idx];   // 兜底
    line.style.opacity = '0';                                        // 只隐藏，不清空
  }
}
```

要点：

- **字幕不参与逐元素入场排序**。它在视觉最底部，排进序列会迟到约 1.3 秒，配音已经开口字幕还没出来；改为切句时 0.18s 淡入，且必须与配音同步。
- 淡入由 `t - sub.start` 确定性计算，不用 CSS transition。
- 静态 HTML 里 `.subline` 已填该场景首句，`SUB_PLACEHOLDER` 只作被外部清空时的兜底。
- 若想让消失也不突兀，可加 0.12s 淡出，但**渲染器的 `state_key` 必须把淡出期算作逐帧变化**，否则会被冻结在半透明。默认保持瞬时消失。

## 5. 几何测量验收（比截图更硬）

`measure_layout.py` 用 CDP 调 `window.__seekTo(t)`，量 `.scene.active` 内所有元素的 `getBoundingClientRect()`，三阶段对比：

1. **消失阶段**：每场景取「最后一句字幕中段」与「场景结束后 0.40s 空档」，要求**全部元素 0 位移**（含 `.subhost` 高度 0 变化）。
2. **换句阶段**：取开场 2.2s 之后（避开入场 `translate`）的每条字幕，要求除 `.subline` 自身宽度外全部 0 位移，且 `.subline` 的 `y` / `h` 恒定。
3. **强制对照**：在同一时间点直接把 `.subline` 换成该页最长与最短字幕，覆盖入场窗口内无法采样的场景。

通过标准：三阶段 `maxDelta == 0.00 px`。修复前报告与修复后报告都留档（`layout-before.json` / `layout-after.json`），`verify_stability.py` 把它们画成位移柱状图，并附「可见 / 消失 / 差异」帧对照；两帧差异 bbox 应**只落在底部字幕行**，面积 0.177%–0.578%。

成片层面再做一次：`verify_video.py` 抽「可见 / 空档」两帧，用阈值 22 过滤 H.264 压缩噪声，统计**字幕行以上区域的差异像素占比 < 0.01%**。注意 `bbox` 对零星噪点过于敏感（一个压缩块就能把框拉到全图），判定要用区域统计，画框时只取字幕行内的 bbox。片尾场景没有空档，应跳过而不是报错。

## 6. 已知取舍：内容近重复

海报本就是拿配音文案排的，字幕进页脚后，01 / 06 / 07 / 08 页会出现上下两句近重复，08 页最明显（引文与字幕几乎同句）。这是文案层面问题，不是版式问题：

- 字幕必须跟配音，不能随意换句；
- 可选方案：给这几页换字幕 / 把页面里重复那句删弱 / 接受；
- 用夜蓝字幕与灰蓝引文把层级拉开能缓解，但文字不改；
- **在交付说明里明确列出，交回用户决定，不要擅自改稿**。
