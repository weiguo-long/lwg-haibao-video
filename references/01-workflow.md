# 阶段 1：分段、海报组与确认节奏

## 1. 分段：把长文切成可独立成页的语义块

目标 6–10 页，每页只承载**一个主句**。原文 110–160 字的段落塞进 3:4 一屏必然糊，压缩成「主句 + 1–2 行辅助小字 / 数据」，完整语义交给配音。

按论证结构切，不按字数平均切。通用骨架（以「时代从不换题」项目为例）：

| 页 | 功能 | 主句 | 构图手法 |
|---|---|---|---|
| 01 | 封面 / 核心命题 | 时代从不换题，它只是不停降价 | 深底左对齐大字 + 右缘竖排水印 + 底部信息条 |
| 02 | 提出误区 | 便宜的位置早没了 | 杂志栏线 + 左右双栏对照 + 角落标签 |
| 03 | 底层机制 | 会变的只有一样：价格 | 左大字 + 右侧几何示意（台阶下移 → 点阵扩散） |
| 04 | 案例一 | 车没变聪明，只是买得起了 | 超大数字对比 + 底部横贯描边英文条 |
| 05 | 案例二 | 没有新航线，只是箱子一样大 | 深底四角信息框架 + 左下超大分数 |
| 06 | 合流金句 | 需求一个字没改 | 全页居中 + 大量留白 + 一道短线 |
| 07 | 行动指令 | 别问风口，问价格 | 中央大字 + 编号清单 + 斜线装饰 + 描边标签框 |
| 08 | 收尾 / 引语 | 时代只奖励把价格打下来的人 | 中央深色竖排条 + 交叉弧线 + 落款 |

**构图必须逐页换**：连续两页用同一手法会让整套看起来像模板套壳。以 `lwg-haibao-design/references/rules.md` 的样本编号排布，选 6–10 个不同 S 编号；深底反转安排在第 1 页与中间某页做节奏重音。

## 2. 配色：一套色板走完全系列

按五角色填满色值：`bg`（纸底）/ `text`（主字）/ `mid`（大字与深色块）/ `accent`（唯一强调）/ `decor`（水印、栏线）。

已验证的 C-01 纸红复古：

| 角色 | 色值 | 用法 |
|---|---|---|
| bg | `#F1E6D8` | 米白纸底，浅底页统一加约 5% SVG 纸纹 |
| text | `#1A1614` | 墨色正文；v2 里兼作字幕条底色，v3 字幕改按页取色 |
| mid | `#28314E` | 夜蓝大字、结论块、竖排条；深底反转页的底色 |
| accent | `#AA2B3A` | 朱红，全系列唯一强调，每页面积 ≤5% |
| decor | `#4A5B78` | 灰蓝小字、英文副标 |

强调色贯穿方式：封面「降价」实心块 → 某数据页的超大数字 → 行动页的关键词块，形成系列呼应。深底反转页只反转 bg/text 明暗关系，不换色板。

## 3. 确认节奏（不可跳）

1. **只交封面**：生成第 1 页 + Chrome 无头 900×1200 渲染核对。交付时说明分段表、色板、选型打分前三、验收结果，并明确问「配色 / 标题字号 / 强调块是否要改」。
2. **确认后出全部页**：用户回复「继续」等确认语后再批量生成，附 4×2 总览拼图。
3. **版式方案有改动时，先出静态设计效果图**：例如从独立字幕条改成「字幕即页脚」，要先用真实海报渲染 8 页效果图给用户确认，再动动画。跳步的代价是动画与视频都得重做。
4. **只交 HTML 动画预览**：配音与动画做完仍不渲染视频，交付 `preview.html` 并等待确认；用户可能改字幕、音色、入场节奏、字幕取色，改一次比重新编码整片便宜得多。
5. **确认后才渲染视频**；成片效果可行后再决定是否把新流程沉淀进技能。

自动化的后台任务完成通知、系统提醒**不算用户确认**。用户没对内容层面的取舍表态时，按原状保留，不要擅自改稿。

## 4. 单页技术规范

- 画布 3:4，`.stage` 声明 `container-type:inline-size`，字号/间距统一用 `cqw`（相对画布宽度），一处改全局缩放。
- 一个自包含 HTML：内联 CSS/JS、语义化文件名（不用 `index.html`）、带 favicon、无僵尸按钮、不用 emoji。
- **v3 默认「字幕即页脚」**：静态海报阶段就把页脚信息 / 页码那一块位置留给字幕，页码、连载标签、英文装饰行、出处行全部取消，`VOL. 01 / 08` 只留期号。规整地留位，比动画阶段再正则清页码更干净。逐页替换规则见 `references/05-subtitle-as-footer.md`。
- v2 历史链路才允许静态海报保留页码，动画阶段由 `build_preview.py` 正则清除。
- 装饰线、短线的高度**一律用 `cqw`**，不用百分比（见 `04-pitfalls.md`）。
- 旋转斜线用 `transform`；若后续要加位移动画，用独立的 `translate` 属性，避免互相覆盖。

## 5. 出稿与验收

按 `lwg-haibao-design/references/selection.md` 打分选型（不许跳过打分），按 `checklist.md` 12 项手算 `cqw → px`、字号阶梯、大小字净距、对比与强调面积。

渲染核对命令：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
  --force-device-scale-factor=1 \
  --screenshot=/tmp/check.png --window-size=900,1200 \
  "file:///abs/path/to/01-cover.html"
```

用图像查看工具逐项核对：文字出界 / 元素压字 / 色面对比 / 留白均衡。每页都要看，不通过就改再重渲染。

总览拼图：4×2 网格，每格缩略图 + 中文标签；PIL 中文字体用 `/System/Library/Fonts/STHeiti Medium.ttc`，画布高度留足标签行（第二行文字被裁时加高 70px 左右）。

## 6. 交付说明要写清

- 分段表（页号 / 原文段落 / 主句 / 构图样本编号）
- 色板与深底反转的页码
- 选型打分前三与第一名为何合适
- 验收方式与实测数值（字号阶梯、净距、对比、强调面积）
- 修过哪几处问题
- 明确请用户确认什么、确认后下一步做什么
